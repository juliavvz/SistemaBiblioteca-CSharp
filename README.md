# 📚 Sistema de Gerenciamento de Biblioteca em C#

Aplicação de console desenvolvida em **C#** para o controle de acervo de livros, gerenciamento de exemplares físicos e registro de empréstimos/devoluções, aplicando conceitos de Orientação a Objetos (OOP).

---

## 🚀 Funcionalidades do Sistema

O sistema conta com um menu interativo contendo as seguintes opções:
- **Livros:** Adicionar novos títulos ao acervo com seus respectivos dados básicos.
- **Pesquisa Sintética:** Consulta os dados de um livro juntamente com o total de exemplares, quantidade disponível, total de empréstimos e percentual de disponibilidade.
- **Pesquisa Analítica:** Exibe os dados do livro, detalhando cada exemplar físico (número de tombo) e o histórico completo de empréstimos e devoluções.
- **Exemplares:** Adicionar novos exemplares físicos vinculados a um livro existente.
- **Empréstimos e Devoluções:** Registro de movimentações dos exemplares com controle automático de disponibilidade.
